# Glossar

| Begriff | Kurzerklärung |
|---|---|
| Backtest | Simulation einer Handelslogik auf historischen Daten, ohne zukünftige Informationen zu verwenden. |
| Bid / Ask | Aktuell bester Kauf- beziehungsweise Verkaufspreis. |
| Canary | Begrenzter Live-Test eines Kandidaten mit sehr kleinem Risikobudget. |
| Champion | Aktuell bevorzugtes und freigegebenes Modell. |
| Challenger | Neuer Kandidat, der gegen den Champion geprüft wird. |
| Drawdown | Rückgang vom bisherigen Kontohöchststand bis zu einem späteren Tief. |
| Exposure | Gesamte wirtschaftliche Abhängigkeit des Kontos von offenen Positionen. |
| Feature | Für das Modell vorbereiteter Eingangswert, etwa relative Preisänderung oder Uhrzeit. |
| Future | Standardisierter, zeitlich befristeter Börsenvertrag auf einen Basiswert. |
| InstrumentId | Plattforminterne stabile Kennung eines handelbaren Instruments, unabhängig von Broker- und Datenanbietersymbolen. |
| Label | Historische Lernvorlage, die beschreibt, welche Entscheidung als gut bewertet wurde. |
| Leakage | Versehentliche Nutzung von Informationen aus der Zukunft beim Training oder Test. |
| Long / Short | Position auf steigende beziehungsweise fallende Preise. |
| MES | Micro E-mini S&P 500 Future. |
| MGC | Micro Gold Future. |
| M6E | Micro EUR/USD Future. |
| MNQ | Micro E-mini Nasdaq-100 Future. |
| Modellartefakt | Auslieferbare Einheit aus Modell, Vertrag, Prüfsumme, Metadaten und Testergebnissen. |
| Normalisierung | Umrechnung von Werten auf vergleichbare Größenordnungen. |
| ONNX | Standardformat, mit dem ein in Python trainiertes Modell in .NET ausgeführt werden kann. |
| Paper Trading | Handel mit Live-Daten und virtuellem Kapital. |
| Profit Factor | Summe der Gewinne geteilt durch die Summe der Verluste. |
| Rollover | Wechsel vom auslaufenden Futures-Kontrakt auf den nächsten. |
| Shadow Mode | Kandidat entscheidet parallel, sendet aber keine Orders. |
| Slippage | Differenz zwischen erwartetem und tatsächlich erreichbarem Ausführungspreis. |
| Spread | Abstand zwischen Bid und Ask. |
| Stop Loss (SL) | Order oder Grenze zur Begrenzung eines Verlusts. |
| Take Profit (TP) | Order oder Grenze zur Sicherung eines Gewinnziels. |
| Walk-Forward-Test | Wiederholtes Training auf Vergangenheit und Test auf dem jeweils folgenden Zeitraum. |
